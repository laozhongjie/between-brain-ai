# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

BETWEEN ("between brain and AI") is a client-only Vite + React 19 + TypeScript app: a Brain ↔ AI comparison ladder, a live 3D brain atlas and a 2D schematic of the same simulation, in Chinese and English. Live at https://laozhongjie.github.io/between-brain-ai/ (repo `laozhongjie/between-brain-ai`; the local folder is still named `brain-dynamics-atlas`).

## Commands

Node comes from nvm: run `. ~/.nvm/nvm.sh` first in a fresh shell.

```bash
npm run dev                     # Vite dev server
npm test                        # vitest run (all tests)
npx vitest run tests/schematic.test.ts   # one test file
npx vitest run -t "no dashes"   # tests matching a name
npx tsc -b                      # typecheck (also the first step of `npm run build`)
npm run lint                    # oxlint (react + typescript + oxc plugins)
npm run build                   # tsc -b && vite build → dist/
npm run check-refs              # network: verifies every DOI / arXiv ref via Crossref / arXiv
```

Every push to `main` runs `npm ci`, `npm test`, `npm run build` and deploys `dist/` to GitHub Pages (`.github/workflows/deploy.yml`). `vite.config.ts` uses `base: './'`, so the build works under any sub-path.

The brain mesh (`public/models/brain.glb`, meshopt-compressed) and `src/data/region_meta.json` are generated by `pipeline/build_brain.py` (conda env in `pipeline/environment.yml`) and committed; only rerun it to change the mesh.

## Architecture

**Routing.** A tiny hash router (`src/route.ts`, `go()` / `useRoute()`); `App.tsx` switches on the first segment: `#/` landing page (`src/home`), `#/atlas` the atlas (3D or schematic view, chosen by `store.viewMode`), `#/ai/...` the Brain ↔ AI section (`src/ai/pages`, lazy-loaded with KaTeX).

**State.** One zustand store (`src/store.ts`): language, view settings, selected/hovered node, focused system, view mode. Hot per-frame data does not go through React: the simulation exposes typed arrays that components read inside `useFrame` / `requestAnimationFrame`.

**Simulation** (`src/sim`), started once in `main.tsx` (`startSimulation`) and ticked every animation frame regardless of the visible view:
- `engine.ts`: a delay-coupled Wilson–Cowan neural-mass network over all graph nodes (`wilsonCowan.ts`, connectivity from `data/connectivity.ts`), plus global brain state (sleep stage, neuromodulators, vitals in `brainState.ts`). Exposes `activity`, `eeg`, `state`, `simTime`.
- `signals.ts`: event-driven pulses travelling hop by hop along pathways (`data/pathways.ts`); `traffic` per pathway.
- `director.ts`: the scripted "day in the life" (`data/scenario.ts`): time of day, events firing pathways, the narration log (`useScenario` zustand store).
- `focus.ts`: single-system mode (tours in `data/tours.ts`).

**Graph data** (`src/data`). `regions.ts` is the bilingual knowledge base keyed by a hemisphere-free `key`; `nodes.ts` builds graph nodes with ids like `lh.precentral`, `brainstem`, `rh.eye` (positions come from `region_meta.json` or literature coordinates). In pathway definitions `$.key` expands to both hemispheres. glTF loading sanitises node names (drops `.`), see `BrainModel.tsx`.

**Views.**
- `src/scene`: React Three Fiber scene. Glass cortex is a `MeshStandardMaterial` patched in `onBeforeCompile` (Fresnel rim); activity drives emissive colour; bloom via `@react-three/postprocessing`. Labels and the hover callout are DOM elements positioned each frame (`Labels.tsx`).
- `src/schematic`: the 2D diagram. `layout.ts` `makeLayout(k)` stretches rows vertically to fill the panel and routes every edge orthogonally (feedforward enters a node's left edge, feedback leaves the bottom and enters the target's bottom); `tests/schematic.test.ts` audits every route (orthogonal, starts/ends on its endpoints, never crosses a node). Pulses and arrival flashes are drawn imperatively in a separate overlay SVG so the static diagram never repaints; pan/zoom moves it with a CSS transform and commits the viewBox when the gesture ends.
- `src/home`: landing page. A sticky stage whose CSS variables (`--hero`, `--fill`, `--open`, `--r`, `--cta`) are set from scroll; the split-disc logo's two halves are `clip-path` circles that grow into the brain (`HomeBrain`, reuses the scene components) and AI (`HomeAI`, 2D canvas) panels. Chapter content in `home/chapters.ts`.

**Brain ↔ AI content** (`src/ai`). Cards are data (`content/layer1..4.ts`, typed in `ai/types.ts`); functional topics (`content/topics.ts`) and the three cross-domain topics (`CROSS_TOPICS`, X01 to X03) share one template, with their pages in `content/topic-pages/` and figures in `figs/topics/`; every card id needs a figure pair in `figs/` (registered in `figs/index.ts`, drawn with the helpers in `figs/kit.tsx`), refs live in `content/refs.ts`, interactive labs in `labs/registry.ts`. Content tests enforce unique ids, resolvable links, a figure pair per card and that every reference is cited.

**Text and i18n.** Every user-facing string is a `Bi` (`{ zh, en }`), translated with `useT()` from `i18n.ts`. Math and symbols in text are written as `$…$` and rendered through KaTeX by `rich.tsx` (`<Rich>`). `tests/text.test.ts` scans all content and fails on any dash (`—` / `——`) and on any formula that does not render.

**Styling.** One global stylesheet, `src/index.css`, with tokens on `:root` (dark theme, ice-blue accent `--accent`); canvas/SVG/WebGL colours mirror them in `src/theme.ts`, and system colours are in `SYSTEMS` (`data/regions.ts`). Panels use the `.panel` glass pattern (cursor spotlight driven by `--mx/--my` from a listener in `main.tsx`). Icons are lucide, referenced by name through `src/ui/Icon.tsx` (data files store icon names, no emoji). Text transitions use `src/ui/DecodeText.tsx`. Fonts are bundled npm packages: Inter (body), MiSans (Chinese), Jost (the BETWEEN wordmark, landing titles, and all titles / tags / small labels via `--label`), JetBrains Mono (numbers and code only, `--mono`). Brain ↔ AI page and section titles use `--label` at a light weight (330), like the landing page's Brain / AI. Inline formulas that are only numbers (`$0.5$`, `$16 \times 16$`) render as plain text, not KaTeX.
